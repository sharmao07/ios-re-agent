# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in this project a respectful experience for everyone, regardless of age, background, identity, experience, or viewpoint.

## Our standards

Examples of constructive behavior include being considerate, giving and accepting helpful feedback, focusing on what is best for the community, and showing empathy toward other contributors.

Unacceptable behavior includes harassment, personal attacks, deliberate intimidation, publishing private information, and using the project to target people or their accounts.

## Scope

This code of conduct applies in project spaces, including issues, pull requests, discussions, and spaces where a person is representing the project.

## Enforcement

Project maintainers are responsible for clarifying and enforcing these standards. If an issue occurs, contact a maintainer privately through a verified contact method. Maintainers will review reports fairly and may remove content or participation that violates these standards.

This is a short project policy inspired by common open-source community guidelines; it is not legal advice.
